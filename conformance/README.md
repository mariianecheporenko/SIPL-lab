# SIPL Conformance Suite (`CORE-06`)

Незалежний набір тестів для перевірки відповідності будь-якої реалізації специфікації мови SIPL.

## Формат `cases.json`
Кожен тест описується JSON-об'єктом:
- `id`: унікальний ідентифікатор тесту;
- `description`: опис сценарію;
- `source`: вихідний код мовою SIPL;
- `expect_valid`: `true` для коректних програм, `false` для синтаксичних або runtime-помилок;
- `expected_state`: очікуваний словник стану змінних після завершення (для валідних програм).
